DỰ ÁN: SÀN TRAO ĐỔI ĐỒ CŨ NỘI BỘ
=====================================

TỔNG QUAN DỰ ÁN
----------------
Dự án xây dựng website cho phép nhân sự trong tổ chức đăng tin rao vặt đồ cũ, tìm kiếm/lọc, nhắn tin đơn giản giữa người mua-bán, và gửi thông báo email.

MỤC TIÊU
--------
- Tạo nền tảng trao đổi đồ cũ nội bộ trong tổ chức
- Hỗ trợ đăng tin, tìm kiếm, chat 1-1, thông báo email
- Phạm vi nội bộ: chỉ người dùng thuộc domain tổ chức hoặc được mời
- Không xử lý thanh toán; chỉ kết nối trao đổi thông tin

CÔNG NGHỆ SỬ DỤNG
-----------------
- Backend: Django 5.2.6 (Python 3.10+)
- Database: SQLite (dev) / MySQL (production)
- Frontend: Django Templates + Bootstrap 5.3.3
- Media: Local storage (dev) / có thể mở rộng S3/MinIO (prod)
- Testing: pytest + pytest-django
- Email: Django EmailMultiAlternatives

TÍNH NĂNG CHÍNH
---------------

1. XÁC THỰC NGƯỜI DÙNG (accounts/)
   - Đăng ký/đăng nhập với OTP verification
   - Quản lý hồ sơ người dùng
   - Session management & CSRF protection

2. QUẢN LÝ TIN RAO VẶT (listings/)
   - Đăng tin: tiêu đề, mô tả, danh mục, giá, tình trạng, ảnh
   - Quản lý trạng thái: PENDING → PUBLISHED
   - Upload & quản lý ảnh sản phẩm
   - Phân trang và sắp xếp

3. TÌM KIẾM & LỌC (listings/)
   - Tìm kiếm theo từ khóa
   - Lọc theo danh mục, tình trạng, khoảng giá
   - Sắp xếp theo giá, thời gian đăng

4. CHAT 1-1 (chat/)
   - Tin nhắn real-time giữa người mua-bán
   - Giao diện messenger-style với Bootstrap
   - Rate limiting cho việc gửi tin nhắn
   - Email notifications khi có tin nhắn mới

5. THÔNG BÁO EMAIL (chat/)
   - Email tự động khi có tin nhắn mới
   - Template HTML + Text
   - Debounce để tránh spam

MÔ HÌNH DỮ LIỆU
----------------

1. User (Django built-in)
   - username, email, first_name, last_name
   - is_staff, is_active, date_joined

2. Category
   - name, slug (unique)
   - Quản lý danh mục sản phẩm

3. Listing
   - title, description, category (FK)
   - condition (new/used), price, currency
   - location, status (PENDING/PUBLISHED)
   - owner (FK to User), created_at
   - Indexes: category+price, created_at

4. ListingImage
   - listing (FK), image (ImageField)
   - alt_text, upload_to function

5. Conversation
   - listing (FK), buyer (FK), seller (FK)
   - created_at, updated_at
   - Methods: is_participant(), other_participant()

6. Message
   - conversation (FK), sender (FK)
   - body, created_at, read_at
   - Rate limiting & validation

```
/                           # Home page
/admin/                     # Django admin
/accounts/                  # Authentication
/listings/                  # Product listings
/chat/                      # Messaging system
  /<int:pk>/               # Thread detail
  /<int:pk>/send/          # Send message
  /start/<int:listing_id>/<int:other_user_id>/  # Start conversation
  /<int:pk>/poll/          # Poll new messages
```
